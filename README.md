# Долината диша

Училищен сайт за екологична инициатива: зимният смог, горските пожари и сметищата в Казанлъшката долина.

## Структура
- `index.html` – съдържанието (една страница, 5 секции)
- `css/style.css` – визията и версията за телефон
- `js/main.js` – меню, анимации, симулатор на небето, обещания
- `img/` – сложете тук `fire.jpg` и `waste.jpg` (собствени снимки)

## Технологии
Чист HTML, CSS и JavaScript, без библиотеки. Canvas за анимациите.

## Пускане
Отворете `index.html` в браузър или качете папката в Netlify / GitHub Pages.
